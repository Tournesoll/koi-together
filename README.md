# 锦鲤上岸

这是灿灿送给熠熠的 200 天纪念小游戏，也是写给我们共同未来的一封小小情书。

集训前的那个晚上，我们聊了很久很久。我们说起各自藏在心里的担忧，说起考研、未来和那些还没有答案的远方。原来，我们都在认真地为彼此、也为共同的明天努力。那天，我们一人画了一尾锦鲤，把希望、勇气和对未来的期待都藏进了画里。

后来，我把那晚的手稿和我们从 100 天走到 200 天的回忆，一点一点做成了这款游戏。

游戏里的熠熠是一尾不断向前游的小锦鲤。她会穿过焦虑、疲惫和偶尔的小情绪，收集我们一起走过的纪念卡片。每一张卡片都是一段真实发生过的幸福，也会成为继续前进的力量。当风浪最急、前路最难的时候，灿灿也会来到熠熠身边。因为这从来都不是一个人的闯关，而是两个人并肩奔赴的旅程。

我们或许会紧张，会疲惫，也会偶尔走慢一点，但没有关系。爱不是让彼此停在原地，而是让我们更有勇气走向自己的远方，也始终愿意站在对方的前途里。

愿两尾锦鲤穿过海浪，越过龙门；愿我们珍藏一路的甜蜜，也拥有奔向未来的坚定。

对的人会站在彼此的前途里。

我们终将携手上岸。

## 游戏方式

- 电脑端使用方向键上下切换赛道。
- 手机端可以点击“向上游 / 向下游”，也可以直接在游戏画面上下滑动。
- 锦鲤会自动发射子弹，击退焦虑、贪吃与生气等小情绪。
- 击败精英怪可以收集纪念卡，点击底部卡牌即可释放属于我们的回忆力量。
